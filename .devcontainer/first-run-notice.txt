Welcome to the Serverless Agents Quickstart Codespace.

Start the agents locally (from the src folder):
```
cd src
cp local.settings.json.sample local.settings.json   # then set FOUNDRY_PROJECT_ENDPOINT
az login
func start
```

Local endpoints:
- Chat API:      http://localhost:7071/agents/main/chat
- Debug chat UI: http://localhost:7071/agents/main/

Or provision + deploy everything to Azure:
```
azd up
```

Docs: https://learn.microsoft.com/azure/azure-functions/functions-serverless-agents-runtime
